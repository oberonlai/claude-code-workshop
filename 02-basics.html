基本觀念與環境

CLAUDE.md、Skill、MCP、Plugin
各管什麼，設定檔又該放哪。

每次都載入的要短，用到才載入的可以長。

每次都載入

CLAUDE.md、記憶檔。
每一輪都在花錢背它，只放不會變的事實。

用到才載入

Skill、MCP / Plugin。
被叫到才進 context，平常零成本。

每次都要知道的是事實，用到才要的是流程。

CLAUDE.md

「我叫小賴」「所有回覆用繁體中文」
每次都要知道，而且很短。

Skill

「先幫我清查老站的文章有哪些類型」
用到那件事才需要載入。

只有一個專案在用的流程，就放專案裡。

~/.claude/skills/

全域。每個專案都吃得到，
但所有專案都要分攤它的描述額度。

.claude/skills/

專案內。跟著 repo 走、可以 commit，
不干擾別的案子。

記錯的記憶，比沒有記憶更貴。

CLAUDE.md

你手寫的事實。永久、可版控、每次載入。

auto memory

Claude 自己記下的。方便，但要偶爾回頭看它記了什麼。

/memory

手動編輯記憶的入口。要改、要刪就從這裡進去。

共用的工具放全域，特殊狀況的放專案設定檔。

my-plugin/
├─ CLAUDE.md　　　　　　　　專案事實：架構、規範
└─ .claude/
　　├─ settings.json　　　　可 commit，團隊共用
　　├─ settings.local.json　個人設定，別進版控
　　├─ skills/　　　　　　　這個外掛專屬的流程
　　└─ agents/　　　　　　　subagent 定義
