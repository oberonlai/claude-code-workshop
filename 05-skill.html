三次載入，對應三種寫法

常駐的寫觸發情境，本文留導航，細節丟外部檔。

description

寫觸發情境，不是功能介紹。它一直常駐在 context 裡。

SKILL.md 本文

只留階段與判斷點。看得出在哪一步、下一步讀哪個檔。

附屬檔

長範例、指令清單、規格表。要用才讀，平常零成本。

最常被問的一題

會被第二個地方叫到的，才抽成獨立 skill。

獨立 Skill

會被別的流程叫到，或想單獨用 / 觸發。
例：「i18n 翻譯」兩個外掛都在用。

附屬檔

只有這個流程的某一步會讀。
例：發版第三步的 SVN 指令清單。

上線、刪資料、推 production

三層一起上，任何一層單獨都不夠。

入口鎖死

disable-model-invocation: true
只有你本人打斜線才動得了。

工具限縮

allowed-tools 只開必要的幾個，不給它多餘的手。

Hook 把關

PreToolUse 攔危險指令。不靠模型自覺。
